# TiPlay 安卓端页面契约

TiPlay 只提供安卓手机与车机浏览器的产品流程。安卓端使用系统主题和原生控件，保留系统栏、显示缺口和输入法安全边距。窄窗口、矮窗口和大字体通过滚动保留所有输入；窗口变化只调整排列，不创建功能不同的首页。

## 主设置

连接状态、iPhone 选择、CarPlay 连接模式、连接／保存并重新连接／断开在同一个主页面。旧三个按钮首页不再是产品入口。正常连接所需的网络与地址配置不能藏进高级设置或折叠区。

CarPlay 连接模式与浏览器网络来源是不同选择：前者决定 iPhone 使用无线还是 USB，后者决定车机浏览器如何访问安卓端。因此 USB 模式仍显示网络配置；不能因 iPhone 使用 USB 而隐藏浏览器需要的热点或现有 Wi-Fi 设置。

连接配置和手机选择作为草稿编辑，不改变正在运行的会话。用户提交连接操作后才保存并连接；返回其他页面或重建窗口保留草稿。断开只停止当前连接，不退出应用，也不立即重新触发自动连接。

开机后自动连接控制开机启动与这次启动的连接请求，独立于每次打开 App 自动连接的偏好。Android 或设备后台启动限制可能阻止开机启动；打开系统设置不代表已获得豁免。

## 浏览器与网络

网页地址简洁显示，配对码与安卓端地址分别显示。异步探测热点期间先显示配置中的端点，无可用配置时显示默认端点，不能将地址字段留空；这不代表已探测到热点地址或确认网络可达。复制链接包含当前显示的端点和配对码，探测完成后更新端点，见 [浏览器协议](TESLA_BROWSER.md)。运行时服务错误、地址不可用和所需权限提示保留，正常页面不重复展示实现细节。

安卓端热点显示实际启用状态。地址修复与地址位于网络输入前；Root／Shizuku 提供读取本机热点信息，其他方式提供系统热点设置入口。读取失败时允许手动输入，不能覆盖读取期间用户已经编辑的内容。

现有 Wi-Fi 复用同网连接，不创建安卓热点，也不自动加入系统 Wi-Fi。网络名称已保存不代表本机已经加入该网络；本机、iPhone 和车机浏览器必须能互访。USB 时 iPhone 的数据通道仍为 USB。

两种网络来源均选择开放、WPA2、WPA3 过渡或 WPA3；选择必须参与实际连接与校验。开放网络隐藏密码并提交空密码，切换回加密类型保留尚未提交的密码草稿。现有 Wi-Fi 的过渡模式允许系统协商 PSK 或 SAE；纯 WPA2／WPA3 必须匹配对应协议。系统隐藏网络信息时不把无法读取误报成已断开。

## 高级设置

高级设置只承载视频、驾驶侧、诊断及实际使用的系统权限。原生车机专用导航、车辆按钮和多指设置手势不作为手机产品入口；上游兼容实现按 [上游同步](UPSTREAM_SYNC.md) 保留。

修改帧率、HEVC 或驾驶侧后，返回操作明确显示“返回并应用”；执行该操作立即应用并重新连接活动 CarPlay。没有这类修改时使用“返回”。主设置尚未提交的连接草稿不得被高级设置覆盖。

权限行反映系统实际状态，返回系统设置后重新读取；不能把点击授权入口等同于已经授权。报告只由用户主动保存、复制或分享，不自动发送，报告中的凭据与协议负载遵循既有脱敏约束。
