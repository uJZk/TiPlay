# TiPlay 重连界面与页面设计收尾

## 范围

本轮实现浏览器全屏等待／重连层：居中 TiPlay Logo、共用预渲染模糊壁纸，以及右上角 Setting／设置入口。PNG 类型加入 App 内置 HTTP 服务器资源类型，Service Worker 同步缓存壁纸。背景的模糊、压暗和染色均在图片中完成，无运行时 CSS 模糊。

网页和 App 后续布局仅记录为 Markdown：

- [网页配对页设计](WEB-PAIRING-DESIGN.md)：无顶栏、无折叠区、安卓地址、按钮下方错误提示、TiPlay 项目链接；W04 复用 W01，W05 不纳入页面清单。
- [App 主页面设计](APP-MAIN-PAGE-DESIGN.md)：A01＋A03 合并，必要选项和关键信息在第一屏，新增车载热点／第三方 AP，移除设置手势及退出应用入口。

实施后续设计时清理非上游冗余代码，保留有效连接逻辑和上游兼容实现。
