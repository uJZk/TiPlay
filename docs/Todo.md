## Playback parameter evidence

behavior, acceptance requirements and vehicle calibration. Current live audio
uses native RTP or PCM-NetEq; live video follows independent native WebRTC timing.
Audio output references deliberately leave source timing/deadlines unknown.
The independent +300 ms live limits are acceptance requirements, not proof that
the current output enforces or physically meets them.

custom URL queue calibration belong to retired browser engines. Their tests and
field traces remain historical evidence, not pending tuning knobs for the current
pipeline. Preserve useful signal observations when investigating clicks, but
