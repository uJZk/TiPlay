# 网页与 App UI 重写

日期：2026-10-11。用户确认网页按 Liquid Glass 方向实现，App 采用 Material 3 Expressive 风格。

## 网页

公网网页与 App HTTP 网页复用 `site/play/`。配对页没有顶栏或折叠区：Logo、标题、同网连接说明、配对码、安卓地址、连接按钮、错误提示、状态／会话操作与项目链接依次呈现。链接文字改为 TiPlay，文案兼容本机热点、局域网和外部 AP。

玻璃卡片使用透光填色、渐变高光、细边缘和阴影；底层直接复用 `reconnect-wallpaper-blurred.png`。高斯模糊及背景亮度已经预渲染到图片中，不使用 CSS filter、backdrop-filter 或运行时模糊。明暗主题采用同一套网页配色与壁纸；浏览器主题上报给 CarPlay 的行为仍保留。输入框直接显示，胶囊按钮至少 48px，键盘焦点轮廓清晰，支持安全区、窄屏／矮屏滚动与减少动态效果设置。

重连继续全屏居中 Logo，共用背景图片；右上角设置按钮采用玻璃胶囊样式。设置返回配对页保留后台会话和重连。错误只在连接按钮下方显示一次；开始连接后清除旧错误。已连接状态仍全屏播放，保留触摸、统计、画面适配和现有视频路径，不另建网页播放页。Service Worker 更新为 v11。

## App

`TiPlayExpressiveUi` 单独承载产品视觉令牌与 View 样式，不复制连接控制器。继续使用现有 Android View 控件和监听器，以 Material 3 Expressive 的形状、配色与层次实现视觉方向；本轮不整体迁移至 Compose 或替换上游设置框架。

主页面采用简短品牌行、强调色状态卡、单一连接操作、连接／浏览器／无线网络分组卡片及辅助入口卡片。宽屏三列，窄屏和大字体滚动。网络来源使用保留 RadioButton 选中语义的分段形状。输入框 56dp、操作至少 48dp、主操作 52dp，卡片 24／28dp 圆角。语言与关于入口并排，必要连接字段不折叠。

App 按系统明暗模式选择中性色；Android 12 以上采用系统动态强调色，旧系统使用绿系备用色。按钮、输入框、分段选择、开关、标题和高级设置卡片使用同一产品样式。高级设置通过 `DiPlayActivity.render()` 的一个手机模式钩子应用样式，保留上游文件、内部标识、持久化、重连提示和监听器。主页面设备／网络选择对话框也复用新样式。

连接配置草稿、明确提交后重连、USB 切换、返回高级设置保留会话等逻辑不另建实现。原生车机不属于产品范围，保留上游实现仅用于后续合并。本轮之前已有的重连验证文档和 RealPhone 测试适配修改仍保留，不属于 UI 重写。
