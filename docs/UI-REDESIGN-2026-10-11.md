# 网页与 App UI 重写

网页采用 Liquid Glass 视觉，App 使用 Android 原生主题和控件。

## 网页

网页源码为 `site/play/`，通过 HTTPS 托管；App HTTP 网页副本已按后续要求移除。配对页没有顶栏或折叠区：Logo、标题、同网连接说明、配对码、安卓端地址、连接按钮、错误提示、状态／会话操作与项目链接依次呈现。链接文字改为 TiPlay，文案兼容安卓端热点和现有 Wi-Fi。

玻璃卡片使用透光填色、渐变高光、细边缘和阴影；底层直接复用 `reconnect-wallpaper-blurred.png`。高斯模糊及背景亮度已经预渲染到图片中，不使用 CSS filter、backdrop-filter 或运行时模糊。明暗主题采用同一套网页配色与壁纸；浏览器主题上报给 CarPlay 的行为仍保留。输入框直接显示，胶囊按钮至少 48px，键盘焦点轮廓清晰，支持安全区、窄屏／矮屏滚动与减少动态效果设置。

重连继续全屏居中 Logo，共用背景图片；右上角设置按钮采用玻璃胶囊样式。设置返回配对页保留后台会话和重连。错误只在连接按钮下方显示一次；开始连接后清除旧错误。已连接状态仍全屏播放，保留触摸、统计、画面适配和现有视频路径，不另建网页播放页。Service Worker 的缓存版本由 `site/play/sw.js` 定义。

## App

App 使用 Android 原生主题提供按钮、输入框、单选、开关与对话框的外观和状态反馈。保留现有 View 控件、监听器及连接控制器；不添加产品自定义颜色令牌、圆角背景或控件装饰。

主页面保留简短品牌行、连接状态、单一连接操作、车机浏览器／连接／无线网络分组及辅助入口。宽屏并排，窄屏和大字体允许滚动，必要连接字段不折叠。网络来源使用原生 RadioButton；布局间距适应窗口大小，不通过固定控件高度覆盖原生尺寸。

主页面、高级设置和选择对话框沿用原生主题，布局处理系统栏、显示缺口和输入法安全边距，避免底部操作被遮挡。保留上游文件、内部标识、持久化、重连提示和监听器；复用上游控件时按原生控件默认值清除继承的自定义外观，保留控件内容、值与操作。

连接配置草稿、明确提交后重连、USB 切换、返回高级设置保留会话等逻辑不另建实现。原生车机不属于产品范围，保留上游实现仅用于后续合并。
