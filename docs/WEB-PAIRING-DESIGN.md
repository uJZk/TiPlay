# TiPlay 网页配对页设计



配对页使用 Liquid Glass 视觉，共用预渲染模糊壁纸；离线缓存版本以 `site/play/sw.js` 为准。所有输入直接显示，错误位于连接按钮下方，项目链接为 TiPlay。

App 首页与主设置的合并设计及 A02 用途核对见 [App 主页面设计](APP-MAIN-PAGE-DESIGN.md)。

## 页面关系与入口

```text
W01 · 网页配对页
 └─ [连接] → W02 · 全屏等待／重连
              ├─ 连接成功 → 同一网页的 CarPlay 已连接状态
              └─ [Setting / 设置] → 返回 W01 · 网页配对页
```

“设置”复用 W01，不另开网页设置面板。返回 W01 时不主动断开连接，保留当前后台重连；重新提交连接信息时才按用户操作重新连接。

- W03 仅表示同一网页的已连接状态，不是独立页面或入口。
- W04 独立网页设置面板从设计清单中取消。
- W05 下载页从本轮页面设计清单中移除，不在配对、等待／重连或已连接状态中提供下载页入口。

收尾合并最新主分支时，重连页的“设置”已复用现有配对入口，独立设置弹窗已删除。配对页新布局已实施；独立下载站点的发布资源继续沿用现有流程。

## 页面布局

页面无顶栏，内容水平居中、垂直略偏上。所有输入项直接显示，不设置折叠或展开区。

```text
页面 · 无顶栏，内容居中
│
├─ TiPlay Logo
├─ 连接 TiPlay
├─ 让这块屏幕与安卓端连接同一网络，
│  输入 TiPlay 显示的配对码，即可显示 CarPlay。
│
├─ 配对码
├─ <输入 4 位配对码>
│
├─ 安卓端地址
├─ <预先填写的 IP:端口，可编辑>
│
├─ [连接]
├─ {错误提示}                      〔出现错误时〕
├─ [Debug 开关]                    保存选择，不重连
│
└─ [TiPlay]                       项目仓库链接
```

## 布局参数

| 布局项 | 设计值 |
| --- | --- |
| 主内容 | 最大宽 400px，水平居中，垂直略偏上 |
| 页面左右留白 | 至少 24px |
| Logo | 72px，距标题 24px |
| 标题 | 28px，居中 |
| 说明 | 15px，居中，行高 1.6 |
| 配对码区域 | 距说明 32px |
| 输入框 | 全宽，高 60px |
| 配对码输入 | 数字居中，最多 4 位 |
| 安卓端地址输入 | 预填当前地址，允许编辑，字号小于配对码 |
| 连接按钮 | 全宽，高 52px，距安卓端地址输入框 16px |
| 错误提示 | 紧接连接按钮下方，仅出错时显示 |
| 项目链接 | 位于页面底部，弱化显示，文字为 TiPlay |

## 状态提示

以下为设计文案。提示显示时位于连接按钮正下方，项目链接之前；实际出现页面遵循现有连接流程，自动重试仍使用全屏等待／重连页（W02）。

| 情况 | 文案 |
| --- | --- |
| 未输入配对码 | 请输入安卓端显示的 4 位配对码。 |
| 配对码格式错误 | 配对码需要 4 位数字。 |
| 配对码不正确 | 配对码不正确，请在安卓端的 TiPlay 中核对。 |
| 安卓端地址格式错误 | 请输入有效的安卓端地址和端口，例如 100.109.220.253:8080。 |
| 安卓端无响应 | 暂时无法连接安卓端，请检查两台设备是否连接同一网络。 |
| 其他浏览器接管 | 画面已在另一块屏幕显示。点击“连接”可切回这里。 |
| 主动断开后返回 | 已断开，输入配对码即可再次连接。 |

## 实施时的代码清理要求

实施本设计时，必须同步删除非上游的冗余代码，不能只隐藏旧界面并保留整套无用实现。高级折叠区相关代码已清理，以下其余清理随对应页面改动执行。

清理范围为本项目新增、已被新设计替代或不再被引用的代码与资源。上游文件、内部标识和仍用于兼容的分类接口按 `AGENTS.md` 保留；仍在使用的连接、播放、触摸和恢复逻辑不得因页面重新归类而删除。

- W04 独立弹窗已在收尾集成中删除：`site/play/settings.js`、`index.html` 中的 `browser-settings` 对话框、对应 CSS 和 `app.js` 中的弹窗钩子均已清理。设置入口调用现有配对流程，保留后台重连；活动会话参数保持锁定，可返回 CarPlay。后续若按新稿允许编辑，须另行实现明确的提交与重连行为。
- W01 移除顶栏和折叠区后，删除相关的本项目冗余样式、事件、文案及状态分支；检查 Debug 和画面调整等仍在使用的操作，避免随容器一起误删。
- 同步清理 Service Worker 预缓存清单中的已删除文件，以及失效的导入、DOM 查询和旧弹窗测试；将测试改为验证“设置返回 W01 且保留重连”。
- W05 从设计清单移除不等于直接删除所有下载资源。若实施时隐藏或移除下载入口，先检查现有下载链接及发布流程，仅删除确认不再使用的本项目实现。
- 重连背景只保留共用的预渲染模糊图片，不重新引入明暗双份壁纸、运行时模糊或额外染色层。

完成后检查无悬空引用、重复控件和未使用资源，并运行适用于改动的检查。涉及网页或 App 实现时，执行 `AGENTS.md` 要求的网页测试及 Android 完整检查；不能把清理未执行的设计记录标记为已完成实现。


## Debug 画面附加层

Debug 取代原统计按钮。开启后，在 CarPlay 画面的上方中央显示五项滚动统计；关闭立即隐藏，不改变连接状态。统计定义、时钟同步、兼容协议与验证限制见 [Debug 实施记录](WEB-DEBUG-2026-10-11.md)。
