sources.lock.json contains fixed source commits, publicly downloadable archives
and SHA-256 checksums for every source dependency, including build framework.
artifacts.json contains the four Android ABI shared-library checksums and ELF
LOAD alignments and prepared source identities. Libraries use 16 KiB page
alignment. TiPlay modifies libjuice to retain IPv4 link-local host candidates,
including IPv4-mapped addresses, for local-only links. IPv4/IPv6 loopback and
IPv6 link-local exclusion remains unchanged. source-patches.json records the
upstream commit, exact patch SHA-256 and target pre/post hashes; the complete
libjuice-ipv4-link-local.patch accompanies this notice. Other dependency
sources remain pinned upstream content. Build flags enable media and DTLS-SRTP
and hide non-C-API symbols. No audio encoder/decoder or microphone capture is used.

The application JNI adapter is TiPlay GPL-3.0-only code, built from:
shared/src/main/jni/rtc-audio/rtc_audio_jni.c
Rebuild instructions and fixed-source fetch/verification are provided in:
scripts/rtc-audio/build.py
scripts/rtc-audio/source-patches.json
scripts/rtc-audio/libjuice-ipv4-link-local.patch
