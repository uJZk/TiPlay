Your iPhone.
At home in your car.

TiPlay runs on an Android device and displays wired or wireless iPhone CarPlay in the car browser.

Download APK ↓How to install

No jailbreak, dongle, account or authentication server required.

Install on the Android device running Android 9 or later. Use its hotspot or existing Wi-Fi so the car browser can reach TiPlay. Compatibility depends on Android, iOS, the network and browser.

TiPlay supports an Android receiver and car browser. Native head-unit installation and product menus are outside its scope.

A familiar drive

01

Install on Android

  1. Download the APK while parked and install it on the Android device.
  2. Open TiPlay and allow the requested permissions. For wireless CarPlay, pair the iPhone with the Android phone over Bluetooth.
  3. Choose Android hotspot or Existing Wi-Fi. Enter the network name, choose its security type and enter a password when required. Connect the car browser to that network.
  4. Choose All (USB first), Wireless or USB for the iPhone connection. Open the link shown by TiPlay in the car browser, enter the four-digit pairing code and select Connect.

Turn on the Android hotspot in system settings, or join the existing Wi-Fi. ADB is not required for ordinary setup.

Release notes & checksums ↗

Before you try it

A public preview, not an Apple-certified product. Authentication uses an experimental accessory identity recovered from public firmware. Browser decoding support, the network and iOS affect playback. The browser reports decoder support automatically. Reduce picture size when troubleshooting.

Updates & signing

TiPlay uses its own app package, com.ujzk.tiplay. It installs alongside DiPlay and does not keep DiPlay’s settings. Install later TiPlay releases over the previous one to keep settings. Test builds use a separate app package.

Report a problem with the latest TiPlay

Reproduce the issue on the latest TiPlay and save a diagnostic report from Advanced settings. Review it before attaching it to a GitHub issue. Include the TiPlay version, Android phone and version, iPhone and iOS, car browser, network, connection mode, expected and actual behavior, and approximate failure time. Reports are not uploaded automatically.
