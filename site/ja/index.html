あなたの iPhone。
車でも、いつもの使い心地。

TiPlay は Android 端末で動作し、有線またはワイヤレスの iPhone CarPlay を車載ブラウザーに表示します。

APK をダウンロード ↓インストール方法

脱獄、専用アダプター、アカウント、認証サーバーは不要です。

Android 9 以降の端末にインストールしてください。ホットスポットまたは既存の Wi-Fi を使用して、車載ブラウザーから TiPlay に接続します。互換性は Android、iOS、ネットワーク、ブラウザーによって異なります。

TiPlay は Android スマートフォンと車載ブラウザーの組み合わせをサポートします。車載 Android 端末向けのインストールや製品メニューは対象外です。

いつもの運転体験

01

Android にインストール

  1. 停車中に APK をダウンロードし、Android 端末にインストールします。
  2. TiPlay を開いて必要な権限を許可します。ワイヤレス CarPlay を使う場合は、iPhone と Android スマートフォンを Bluetooth でペア設定します。
  3. Android のホットスポットまたは既存の Wi-Fi を選び、ネットワーク名とセキュリティ方式、必要なパスワードを入力します。車載ブラウザーもそのネットワークに接続します。
  4. iPhone の接続方法を「すべて（USB 優先）」「ワイヤレス」または「USB」に設定します。車載ブラウザーで TiPlay のリンクを開き、4 桁のペア設定コードを入力して接続します。

Android のシステム設定でホットスポットをオンにするか、既存の Wi-Fi に接続してください。通常のセットアップに ADB は不要です。

インストールと接続のヘルプ ↗
02

スマートフォン接続とブラウザー表示

  • ワイヤレスまたは USB で iPhone を接続し、CarPlay を車載ブラウザーに表示します。
  • Android のホットスポットと既存の Wi-Fi を同じメイン接続画面で設定できます。
  • ブラウザーのウィンドウに合わせて映像サイズが変わります。ペア設定には 4 桁のコードを使用します。

試す前に

公開プレビューであり、Apple 認証製品ではありません。公開ファームウェアから取得した実験的なアクセサリー識別情報を使用します。映像と音声はブラウザーのデコード機能、ネットワーク、iOS に依存します。ブラウザーがデコーダー対応状況を自動通知します。問題がある場合は映像サイズを小さくしてください。

更新と署名

TiPlay のパッケージは com.ujzk.tiplay です。DiPlay と同時にインストールできますが、その設定は引き継ぎません。TiPlay の更新を上書きインストールすると設定を保持できます。テスト版は別のパッケージを使用します。

最新の TiPlay の問題を報告してください

最新の TiPlay で問題を再現し、詳細設定から診断レポートを保存してください。内容を確認してから GitHub の Issue に添付し、TiPlay のバージョン、Android スマートフォンとバージョン、iPhone と iOS、車載ブラウザー、ネットワーク、接続方法、期待した動作と実際の動作、発生時刻を記載してください。レポートは自動送信されません。
