# Synthetic media fixtures

`embedded-tx3g.mp4` is a 16×16 black H.264 test video with two real MPEG-4 Timed Text
samples, generated by FFmpeg 7 from an original SRT fixture. It contains no third-party
media. Recreate with a four-second 1 fps `color=c=black:s=16x16:r=1:d=4` lavfi input,
`-c:v libx264 -pix_fmt yuv420p -c:s mov_text -movflags +faststart` and English subtitle
metadata. Expected cues are 0.5–1.5 s “Embedded & safe” and 2–3 s “Second line”.
This fixture was used by the retired custom subtitle parser. It is retained as an
original media input; its presence does not establish AVPlayer subtitle support.

`embedded-cea608.ts` is another original black 16×16 H.264 fixture. A GA94/ATSC
SEI message before its first IDR contains CC1 resume-caption-loading, row-position,
“HI”, and end-of-caption commands. FFmpeg remuxes the elementary stream to MPEGTS
without transcoding (`-fflags +genpts -r 1 -c:v copy`); the source encoder uses
`-tune zerolatency -bf 0`. The retired subtitle test exercised Mediabunny MPEGTS demuxing and the custom
SEI decoder. Those components and tests are removed; CEA-608 acceptance is not claimed.

`airplay-aac-lc.m4a` is an original 0.2-second 1 kHz sine generated with FFmpeg
(`sine=frequency=1000:sample_rate=44100:duration=0.2`, stereo AAC-LC at 96 kbps).
`airplay-aac-lc.json` contains its actual AudioSpecificConfig and ten raw encoded
packets, originally extracted with Mediabunny Input/EncodedPacketSink (no longer a runtime dependency). Decoder
unit tests and browser checks decode these bytes with the current libav.js Worker
path. The earlier WebCodecs smoke results are historical. No fixture contains third-party recordings.

`airplay-opus.ogg` and `airplay-opus.json` contain a synthetic 0.2-second stereo 440 Hz
Opus stream generated by FFmpeg (`-f lavfi -i sine=frequency=440:sample_rate=48000
-t 0.2 -ac 2 -c:a libopus -b:a 64k`). The JSON stores the original OpusHead and raw RTP-compatible packet bytes,
originally extracted with Mediabunny, for codec and transport test inputs.

`photo-exif6.jpg` is a synthetic solid-color 120×80 JPEG with EXIF orientation 6.
The browser displays it as 80×120. The photo E2E uses this original fixture through
the authenticated resource route under the real page CSP; no personal image or
location metadata is included.

Small original HLS-TS and CMAF test patterns are described in the [HLS fixture notes](hls-ts/README.md).

`live-alac24.json` is an original 0.1-second stereo 997 Hz signal generated with
`aevalsrc=0.125*sin(2*PI*997*t):s=48000:d=0.1` and encoded by native FFmpeg ALAC
using `-sample_fmt s32p`. The cookie declares 24-bit ALAC. Packet and extradata
bytes come from `ffprobe -show_packets -show_streams -show_data -of json`.
It validates the software S32-planar to PCM16 path, not 24-bit output fidelity.
